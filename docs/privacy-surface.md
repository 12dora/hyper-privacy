# 防护范围与规则覆盖

本文说明 HyperPrivacy 拦截哪些类型的数据上报、哪些服务会保持正常，以及各项按应用防护功能的作用。实际生效的规则以应用内的规则列表与[更新日志](../CHANGELOG.md)为准；数据采集方式的科普见 [应用是怎么收集隐私数据的](collection-techniques.md)。

## 1. 概览

- **系统应用**：内置 110 条规则，覆盖 123 个系统与厂商预装应用，默认开启 97 条。
- **用户安装的应用**：特征库收录 210 个追踪 SDK（其中广告类 71 个），可按应用、按 SDK 开启拦截。
- **原则**：只拦截数据上报通道，账号、推送、云同步、更新、支付等服务保持可用；会影响功能的规则写明影响并默认关闭。

内置规则综合公开资料、安装包静态分析与真机网络行为核验制定，每条规则都附有来源说明，并随系统与应用更新持续维护。

判定口径：

- **上报**：事件埋点与统计、A/B 曝光记录、日志 / 崩溃 / 性能上传、广告请求与回传、应用列表与应用活动上传、设备指纹采集、定位与 Wi-Fi / 基站采集、输入法使用统计。
- **服务**：账号、推送、云同步、查找设备、系统与应用更新、应用商店、功能所需的云配置、天气与定位查询、云输入与语音识别、病毒库更新、支付、客服。服务不拦截。
- 同一服务器既提供服务又接收上报时，只拦截上报接口，正常服务照常工作。

### 高风险默认阻止

通讯录、短信原文、应用列表、设备指纹、短信链接这类数据一旦泄露，后果比失去一个辅助功能严重得多。下面 9 条规则虽然会带来副作用，仍然默认开启，影响写在规则详情中，可逐条关闭。

| 规则 | 拦截内容 | 影响 |
|---|---|---|
| `securitycenter.traffic-sms` | 流量纠错时上传运营商短信原文与设备标识 | 无法提交流量纠错 |
| `sogou-ime.contacts` | 预装输入法上传通讯录 | 无法生成云端通讯录词库 |
| `assistant.app-sync` | 负一屏上传全量应用列表 | 新装应用的小部件推荐可能缺失 |
| `guard.app-detect` | 应用云检测上传已安装应用列表 | 云端应用风险识别不可用 |
| `securitycenter.url-detect` | 链接云检测上传短信与网页中的链接 | 云端链接检测不可用 |
| `securitycenter.promo-cards` | 安全中心运营卡片请求（附带已安装包名） | 推荐卡片与省电建议不再显示 |
| `vipaccount.usage-upload` | 社区上传应用使用记录 | 依赖使用记录的成长任务无法完成 |
| `systemhelper.firewall` | 运营商终端管理上报设备、SIM、基站与位置信息 | 运营商终端登记失败 |
| `joyose.game-list` | 游戏加速上传新装应用包名 | 可能识别不到新装游戏 |

下面 13 条规则会影响安全、支付、账号、定位等功能，或属于用户主动参与的项目，默认关闭，需要时手动开启。

| 规则 | 拦截内容 | 影响 |
|---|---|---|
| `securitycenter.cloud-scan` | 云查杀 | 云端查杀失效，本地病毒库仍可用 |
| `securitycenter.quake-sensor` | 地震监测志愿者的传感器数据 | 已加入的志愿者不再贡献数据 |
| `feedback.upload` | 问题反馈与日志提交 | 无法提交问题反馈 |
| `simactivate.firewall` | SIM 激活服务整体断网 | 基于 SIM 的快捷登录与号码认证可能失效 |
| `simactivate.tee-report` | 安全校验失败时的设备标识上报 | 可能影响账号登录 |
| `simactivate.activation-receipt` | SIM 激活回执 | 可能影响 SIM 卡激活 |
| `weather.ads` | 天气中的广告 | 生活指数详情与资讯页可能无法加载 |
| `payment.checkout-track` | 收银台埋点 | 可能影响支付收银台 |
| `payment-sdk.logs` | 第三方支付组件的日志与终端上报 | 可能影响第三方支付 |
| `location.uplink` | 查找设备与网络定位服务中的定位数据上传 | 可能影响查找设备与网络定位 |
| `sofire.domains` | 输入法内的账号安全设备指纹 | 第三方账号登录的设备校验可能失败 |
| `ct-autoreg.http` | 运营商自注册（网络） | 运营商入网登记失败 |
| `ct-autoreg.sms` | 运营商自注册（数据短信） | 运营商入网登记失败 |

## 3. 按数据类型的覆盖

| 数据类型 | 拦截的上报 |
|---|---|
| 设备标识 | 系统 ID 服务向第三方应用返回全零标识；拦截设备指纹与统一设备标识 SDK 的上报、运营商终端登记，以及随埋点附带的标识 |
| 应用列表与应用活动 | 拦截全量应用列表、应用激活与安装来源统计、应用生命周期上传；可按应用隐藏已安装应用（第 7 节） |
| 使用行为 | 拦截系统统计 SDK 与预装应用自有埋点，以及应用内嵌的第三方统计 SDK |
| 位置、Wi-Fi 与基站 | 拦截定位众包采集、位置轨迹上传与定位统计；定位查询本身属于服务，保留 |
| 通讯录、短信与链接 | 拦截输入法上传通讯录、流量纠错上传短信原文、链接云检测上传短信链接 |
| 输入内容 | 拦截输入法的输入行为统计与日志；云输入与语音识别属于服务，保留 |
| 屏幕内容 | 拦截屏幕识别组件的运行日志与统计；用户主动触发的识别属于服务 |
| 音频 | 拦截语音助手的埋点与调试转存；语音识别本身保留 |
| 日志、崩溃与性能 | 拦截系统诊断、远程日志提取以及第三方崩溃与性能监控 SDK 的上传 |
| 硬件信息 | 拦截硬件、存储寿命与传感器信息的诊断上传 |
| 广告 | 拦截系统广告服务、厂商广告 SDK 与第三方广告联盟的请求与回传 |

## 4. 保持正常的服务

以下功能所需的通道不拦截，开启模块后照常工作：

- **账号与登录**：账号登录、鉴权与一键登录。
- **推送**：消息推送的注册与送达。
- **云服务**：云同步、相册与便签同步、查找设备。
- **更新与商店**：系统更新、应用商店浏览、下载与更新检查。
- **云配置**：功能运行所需的配置下发。
- **安全**：病毒库更新、云端检测、地震预警、紧急求助等安全功能本身。
- **隐私同意**：同意与撤回操作照常可用，撤回不会因拦截而失效。
- **定位、天气与地图**：网络定位、天气查询与地图服务。
- **输入与语音**：云输入与语音识别。
- **支付与钱包**：支付、公交卡与实名认证。
- **家人守护**：由用户开启的使用时长管理。
- **客服**：用户发起的客服与远程诊断。
- **游戏加速**：网络加速与游戏配置。

有些服务请求本身就必须带上数据，例如网络定位需要 Wi-Fi 与基站信息、云输入需要上传正在输入的文字、更新检查需要已安装版本。这些属于服务的必要输入，模块不处理，可在对应功能的设置中关闭。

## 5. 用户安装的应用

在「应用」页为某个应用开启防护后，模块在本机离线识别其中内置的追踪 SDK，并在该应用内拦截这些 SDK 的上报。

- **离线识别**：在模块自身进程内解析安装包，不执行目标应用的代码，不联网；应用更新后重新识别。
- **特征库**：收录 210 个 SDK，来源为 SDK 厂商的公开文档、公开发布的 SDK 制品与真机安装包分析。分类可重叠：统计分析 73、广告 71、广告归因 24、设备识别 23、推送 21、崩溃与性能 21、用户画像 13、位置 9。
- **可拦截范围**：其中 155 个可拦截，其余仅识别并列出，例如推送 SDK。
- **默认策略**：可能影响登录、支付验证、应用内更新或积分墙奖励的 15 个 SDK 默认不拦截，可按应用逐个开启。推送、登录、地图等 SDK 正常功能所需的通道始终保留。
- **按来源拦截广告 SDK**：广告请求和广告页面按发起它们的代码来源拦截，不只依赖域名，SDK 换域名、改包名或以插件形式加载时同样有效。应用自身的代码不受影响；广告 SDK 自带的隐私同意弹窗保持正常可用；被拦截的广告页面会被安全关闭。
- **疑似广告组件**：不在特征库中、但看起来像广告组件的代码会单独列出，默认不拦截，由你决定。
- **生效方式**：开启后在 LSPosed 通知中确认作用域，重新启动该应用即生效；全局暂停同样适用。
- **加固应用**：识别不到 SDK 的加固应用，可开启「拦截全部已知追踪」（第 6 节）。

## 6. 按应用的隐私增强

以下功能只作用于你开启防护的第三方应用，可按应用单独开关。

| 功能 | 作用 | 默认 |
|---|---|---|
| 隔离 DRM 设备号 | 每个应用读到的 DRM 设备号互不相同，无法借它跨应用关联；音视频授权与播放不受影响 | 开启 |
| 强制系统 DNS | 阻止应用绕过系统 DNS 使用私有解析服务，让域名规则看得到真实目的地；浏览器与网络工具中你自选的加密 DNS 照常可用 | 开启 |
| 随机化硬件指纹 | 为不同应用提供互不相同的部分免权限硬件特征值，降低跨应用设备关联；常规功能与机型信息不受影响 | 关闭 |
| 保护传感器数据 | 适度降低该应用读到的部分传感器与电池读数的精度和刷新频率，减少设备指纹与侧信道推断；系统的自动亮度、屏幕旋转与电量显示不受影响。高精度测量、专业相机、体感游戏与气压计相关功能可能受影响 | 关闭 |
| 拦截原生网络请求 | 让应用原生代码中的常见域名请求同样遵循已开启的域名规则；仅支持 64 位应用，开启后需重启该应用，未开启时没有额外开销 | 关闭 |
| 拦截全部已知追踪 | 不论是否识别到，对该应用套用特征库中所有默认拦截的 SDK 的上报规则，适用于加固后识别不到 SDK 的应用；保留通道照常放行 | 关闭 |

以上功能不作用于厂商应用，以免影响账号、钱包与查找设备等依赖设备标识的厂商服务。

## 7. 系统层隐藏

以下功能只面向第三方应用。首次启用和每次更新模块后需要重启一次手机；之后开关与名单修改即时生效。

| 功能 | 作用 | 默认 |
|---|---|---|
| 隐藏标识类设置项 | 对第三方应用隐藏系统设置中含账号、设备标识及应用列表的非标准条目，并把自定义设备名与蓝牙名称替换为机型名称；常规系统设置与投屏、局域网传输不受影响 | 开启 |
| 隐藏已安装应用 | 让指定应用看不到你安装的其他第三方应用；常用的社交、分享、登录、支付与地图类应用默认仍可见（名单可调整），「严格模式」下一并隐藏 | 不隐藏 |
| 隐藏本模块 | 默认对第三方应用隐藏 HyperPrivacy。开启时第三方商店与更新工具也无法发现本模块，需要通过它们更新时可临时关闭（即时生效） | 开启 |

## 8. 诊断模式

开启后，模块记录已启用防护的应用的外连情况（应用、主机与路径前缀）及是否被拦截，并在设置页列出；可以导出不含个人信息的报告。建议在系统更新后、或发现异常耗电与流量时开启一段时间，把新出现的上报通道反馈给我们，帮助补充规则。规则健康检测会在应用更新后提示「已失效」或「待复核」的规则。

## 9. 防护边界

- 部分原生代码、自建加密网络栈或非标准网络方式发起的采集，可能不在覆盖范围内。
- 夹带在必须保留的服务（推送、登录、地图等）中的数据，以及与正常业务混在同一接口中的上报，无法单独剔除。
- 加固、加密或运行时下发的代码，以及特征库之外的 SDK，可能无法被识别。
- 写在应用自有代码中、或由服务器在普通内容中混排的广告与统计，无法与功能区分。
- 部分无需权限即可读取的底层系统与硬件特征难以彻底消除。
- 服务器依据 IP、账号所做的关联，以及你主动授予的权限，不在手机端可控的范围内。
- 应用列表隐藏与模块自隐藏覆盖常见的查询方式，不保证对抗所有探测手段。
- 防护是尽力而为的：为保证应用与系统稳定，遇到无法确认安全的情况时优先放行。
- 与其他同类模块同时启用可能重复拦截或互相干扰，首页会提示已发现的重叠模块。
